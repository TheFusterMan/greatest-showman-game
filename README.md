# The Greatest Showman

### Что это за игра?
Ритм-аркада в театральной стилистике. Игрок управляет шоуменом на сцене, танцует в такт музыке, срывает овации зала и разгоняет снобов-критиков взрывами конфетти.

### Как управлять?
- **WASD / Стрелки** — шаги и перемещение по сцене. 
- **[ P ] или [ ESC ]** — пауза.
- **[ C ]** — переключение режима «Репетиция», убирающего необходимость попадать в бит для совершение рывка.
- **[ ПРОБЕЛ ] в такт биту** — рывок, уничтожающий критиков. Нажатие мимо такта игнорируется.
- **[ ПРОБЕЛ ] после проигрыша** — сыграть на бис.

### Что должен делать игрок?
- Двигаться в такт метроному (126 BPM) и ловить золотые софиты прожектора на паркете.
- Умножать комбо и зарабатывать очки оваций (`APPLAUSE`).
- Разгонять критиков пируэтом строго в такт музыке, не допуская столкновения без рывка.

### Что пока не реализовано?
- Логическое завершение игры победой
- Мобильное сенсорное управление.
